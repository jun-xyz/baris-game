# 로봇 바리스타 되기 100초

바리스브루(XYZ의 로봇 바리스타 솔루션) 홍보용 픽셀아트 미니게임. 레일 위 로봇 팔이 되어 100초 동안 주문을 받고, 컵을 집고, 기계에 걸어 두고 다음 컵을 집는다. 끝나면 같은 100초에 실제 바리스가 만드는 잔 수와 비교한다.

- 플레이: https://jun-xyz.github.io/baris-game/
- 구조: `index.html`(화면) · `game.js`(순수 상태 머신) · `test.mjs`(`node test.mjs`) · `docs/`(설계 메모)
- 바닐라 HTML/CSS/JS, 빌드 없음. 로컬은 아무 정적 서버로 폴더를 열면 된다.
